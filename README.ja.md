# EML Viewer

メール（.eml）を VS Code で読むための拡張機能です。[English](README.md)

## できること

- .eml を開くと、自動でメールの形で表示します。
- ブラウザーが扱える文字コードに対応しています。UTF-8、ISO-8859-*、Windows-125x、KOI8-R、GBK、GB18030、Big5、EUC-KR、ISO-2022-JP、Shift_JIS、EUC-JP などです。①や㈱などの機種依存文字、半角カナも読めます。
- 件名・差出人・添付ファイル名の符号化（`=?ISO-2022-JP?B?...?=`、RFC 2231）を元に戻します。
- 本文は HTML、テキスト、ヘッダー一覧を切り替えて見られます。
- 添付ファイルをクリックすると保存できます。本文に埋め込まれた画像はそのまま表示します。
- 画面は VS Code の表示言語に合わせて、日本語か英語で表示します。

## 文字コードの指定がないメール

文字コードの指定がない本文は、まず UTF-8 として読み、次に VS Code の表示言語に応じた古い文字コード（日本語なら EUC-JP、Shift_JIS）を試し、最後に Windows-1252 として読みます。表示言語と異なる言語で書かれたメールでは、文字化けすることがあります。

## 安全のための動き

- メールの中のスクリプトは動きません。
- 外部コンテンツは、初期状態では読み込みません（開封の確認に使われることがあるため）。必要なときだけ「外部コンテンツを表示」を押してください。
- リンクは http、https、mailto だけをブラウザーで開きます。

## インストール

Marketplace では公開していません。パッケージを作ってからインストールします。

1. `npm run package` を実行します。Node.js 18 以降が必要で、ほかに入れるものはありません。
2. VS Code で「Extensions: Install from VSIX...」を実行し、`dist/` の .vsix ファイルを選びます。

## 元のテキストを見たいとき

画面右上の「ソースを表示」を押すと、通常のテキストエディターで開きます。
戻すときは、エディター右上の「EML Viewer で開く」を押します。

## 既知の制限

HTML 本文にフォーカスがある間は、Ctrl+P などの VS Code のショートカットが効きません。安全のために本文を別の枠に分けているためです。先に件名などヘッダーの部分をクリックしてください。
